# Agentic PLC

Companies that run themselves. A holding company that instantiates operating businesses run by agents.

## Local

```bash
cp .env.example .env.local
npm install
npm run dev
```

The Clerk streams from SpaceXAI (`https://api.x.ai/v1`, `grok-4.6`) when `XAI_API_KEY` is set.

## Production

DigitalOcean App Platform. Domain: agenticplc.com.
